GreenCare

多國語言隨身電子病例

你的健康資料，清楚地放在掌心。

一份以綠色系設計的離線電子病例模板。可在瀏覽器直接填寫、儲存、匯出與列印；介面支援七種語言。

離線優先 七國語言 單一 HTML 可列印

基本個人資料

建議只填寫醫療情境真正需要的資訊。

緊急聯絡人

需要時讓醫療人員快速找到聯絡方式。

醫療識別

可記錄健保 / 保險等非敏感識別資訊。

家族病史

記錄與直系親屬相關的重要疾病或遺傳資訊。

手術 / 住院史

可記錄手術、住院與重要醫療處置。

目前 / 過去用藥

藥物名稱、劑量與頻率請依醫囑填寫。

過敏史

包含藥物、食物或其他過敏原。

重要健康資訊

填寫醫療人員需要知道的長期狀況或特殊注意事項。

隱私提醒：這個 HTML 檔案可離線運作，但你填入的資料仍會保存在裝置上。請勿把完整病例放在公開或共用電腦；匯出的 JSON 也應妥善保管。

醫療備註

可記錄重要醫療資訊、就診摘要或希望醫師注意的事項。
